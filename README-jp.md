# 📥 My Video Downloader (YT-DLP Windowsバッチラッパー)

強力かつ完全自動化された、依存関係不要（Pythonのインストールも不要！）なWindows用動画一括ダウンロードツールです。[yt-dlp](https://github.com/yt-dlp/yt-dlp)と[FFmpeg](https://www.gyan.dev/ffmpeg/builds/)をコアに採用し、究極の効率性と直感的な使いやすさを追求して設計されています。

---

## ✨ 主な機能

- **依存関係不要の環境**: Pythonを手動でインストールする必要はありません。初回実行時に、最新の`yt-dlp.exe`と`ffmpeg.exe`が自動的にダウンロード・更新されます[cite: 1]。
- **スマートなクリップボード検出**: 有効化後、クリップボードから動画URLを自動的に読み取ります。Enterキーを押すだけで直接ダウンロードできるため、手間を省きたいユーザーに最適です[cite: 1]。
- **マルチプラットフォーム対応**: YouTube（プレイリストやShortsを含む）、Bilibili、TikTok、X (Twitter)、Facebookなど、主要なプラットフォームを完全にサポートしています[cite: 1]。
- **豊富なフォーマット選択**:
- 最高画質（4K/2K/1080p）での自動マージ、字幕やカバーアートの埋め込みに対応しています[cite: 1]。 
- 1080pや720pへの解像度制限オプションも用意されています[cite: 1]。 
- 高品質な音声抽出（MP3 320k / M4A）や、プレイリストの一括ダウンロードに対応しています[cite: 1]。
- **高度な機能**:
- `cookies.txt`の使用に対応しており、メンバー限定動画や閲覧制限のある動画のダウンロードも可能です[cite: 1]。 
- ローカルまたはシステムのNode.js / Denoランタイムを自動検出し有効化します（複雑なボット対策認証を回避するために使用）[cite: 1]。 
- カスタムプロトコル呼び出しやCLIクイックパラメータに対応しています[cite: 1]。

---

## 🚀 クイックスタート

1. このリポジトリから`dl.bat`をPCにダウンロードします。
2. `dl.bat`をダブルクリックして実行します。 3. スクリプトは、必要なコアツール（`yt-dlp` および `ffmpeg`）を自動的に確認・ダウンロードします[cite: 1]。
4. プロンプトに従ってURLを貼り付けるか、単にEnterキーを押してクリップボード内のURLを使用すれば、スムーズにダウンロードが開始されます！

---

## ⌨️ コマンドライン・上級者向けの使い方

コマンドライン（CLI）での操作を好む方向けに、便利なショートカット引数も用意されています：

:: 1. 対話モード（直接実行）
```batch
dl.bat
```
:: 2. CLIでのクイックダウンロード（URL + フォーマットオプション 1～6）
```batch
dl.bat "[https://www.youtube.com/watch?v=xxx](https://www.youtube.com/watch?v=xxx)" 1
```
:: 3. コアツール（yt-dlp）の更新
``` batch
dl.bat -u
```
:: 4. ヘルプと詳細ドキュメントの表示
```batch
dl.bat --help
```
